# E-Commerce ERP Management System

A SQL-based **E-Commerce ERP Management System** developed using **MySQL 8.x**. The project manages customers, products, suppliers, warehouses, inventory, orders, payments, and shipments.

The main purpose of this project is to demonstrate practical knowledge of **SQL, relational database design, joins, subqueries, CTEs, aggregate functions, views, stored procedures, functions, transactions, constraints, and indexing**.

---

## 📌 Project Overview

The E-Commerce ERP Management System is designed to manage the core database operations of an e-commerce business.

It provides a structured relational database for managing:

- Customer information
- Product catalog
- Product categories
- Suppliers
- Warehouses
- Inventory
- Customer orders
- Order items
- Payments
- Shipments

The project focuses on database design and SQL operations commonly used in real-world ERP and e-commerce applications.

---

## 🎯 Project Objectives

- Design a normalized relational database.
- Establish relationships using Primary Keys and Foreign Keys.
- Manage products and inventory across warehouses.
- Track customer orders and order items.
- Manage payments and shipment information.
- Write complex SQL queries for business analysis.
- Implement Stored Procedures and Functions.
- Use Views for reusable queries.
- Implement Transactions for data consistency.
- Use Indexes to improve query performance.
- Practice SQL concepts relevant to ERP systems.
